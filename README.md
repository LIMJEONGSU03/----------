# 풍속 예측 데이터와 평가

## 자료

- `asos_108_2023_2024.csv`: 원본 시간별 관측 자료. 작업 과정에서 수정하지 않았습니다.
- `wind_dataset.csv`: 시간축을 1시간 간격으로 정렬한 뒤, 필요한 입력 및 정답이 모두 있는 행만 모은 데이터셋.
- `predictions.csv`: 2024년 12월 평가 구간의 실제 풍속과 두 예측 방법의 결과.
- `prediction_week.png`: 2024년 12월 1일 00시부터 12월 7일 23시까지의 실제값 및 예측 그래프.

## 학습 데이터 구성

`wind_dataset.csv`의 각 행은 예측 시각과 그로부터 1시간 뒤인 정답 시각을 별도로 기록합니다. 입력 변수는 예측 시각의 풍속, 기온, 습도 및 1시간 전과 2시간 전의 풍속입니다. 정답은 정답 시각의 실제 풍속이며 입력 변수에 포함하지 않습니다.

필요한 시각이나 값이 빠진 행은 채우지 않고 제외했습니다. 시간별 시간축으로 확장했을 때의 행 수는 17,544행이며, 입력과 정답이 모두 유효한 데이터셋은 17,464행입니다.

## 학습 및 평가

모든 시각은 KST 기준입니다. 정답 시각이 2023년 1월부터 2024년 11월까지인 16,720행으로 선형회귀를 학습하고, 2024년 12월의 744행으로 평가했습니다. 평가 기간에는 모델을 다시 학습하지 않았습니다.

회귀 입력은 현재 풍속, 1시간 전 풍속, 2시간 전 풍속, 현재 기온, 현재 습도입니다. 음수 회귀 예측값은 0으로 제한했습니다. 같은 평가 행에서 현재 풍속을 그대로 다음 시각의 예측값으로 사용하는 기준 방법과 MAE를 비교했습니다.

| 예측 방법 | 2024년 12월 MAE |
|---|---:|
| 현재 풍속 유지 (기준) | 0.653495 m/s |
| 선형회귀 (음수 예측은 0) | 0.594577 m/s |

`predictions.csv`에는 예측 시각, 정답 시각, 실제 풍속, 현재 풍속 기준 예측, 선형회귀 예측을 저장합니다. 파일에는 2024년 12월 평가 행 744개가 있습니다.
